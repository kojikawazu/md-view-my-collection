# エラーハンドリング

- **バリデーション必須**: ユーザー入力・外部入力は必ずバリデーションする。スキーマの正準は `front/src/schemas/`（zod）、ランタイム検証は `front/src/lib/validation.ts`（zod アダプタ）を参照。
- **ドメイン層の制約**: ドメインモデル・値オブジェクトで防げる不正値は、コンストラクタ/ファクトリで弾く。
- **ハンドラー層の検証**: ドメイン層で防げないリクエスト形式・型チェックは、Route Handler 層で検証する。
- **HTTP ステータスコード**: 適切なステータスコードで返す（400/401/403/404/500）。
- **統一エラーレスポンス**: エラーレスポンスの JSON 構造を統一する（`{ error: string }`）。
- **ログ**: エラー時は `console.error` でスタックトレースを含むログを出力する。センシティブ情報（メールアドレス・トークン等）はログに含めない。
- **重要操作ログ**: ログイン/ログアウト/投稿/編集/削除は `console.info` で記録する。
