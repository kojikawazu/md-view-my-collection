# Codex ルール

- **AGENTS.md の階層適用**: リポジトリ直下から変更対象までのすべての祖先ディレクトリにある `AGENTS.md` を読み、指示を合わせて守る。ルール本文の正本は `.claude/rules/` とし、AGENTS.md へ複製しない。
- **Claude 固有機能の読み替え**: `CLAUDE.md`、ショートカット、スキル内で Claude Code 固有の機能・スキル名が指定されている場合は、利用可能な Codex の機能・指示へ意図を保って読み替える。読み替えられない場合は、作業を進める前にユーザーへ確認する。
- **GitHub 操作**: Codex は PR の承認・マージを実行しない。ユーザーが承認・マージを完了した後は、PR のマージ状態を確認してから main の最新化など必要なローカル後処理だけを行う。
- **ルールの同期**: `.claude/rules/` のファイル追加・削除・改名・適用範囲変更は、入口ファイルの更新と**同じ変更セット**で行う。同期先は `documentation.md` の影響マップを正本とする（ここに再掲しない）。本プロジェクトの入口は `CLAUDE.md` と `AGENTS.md` の 2 つで、README.md はルール一覧を持たない。
