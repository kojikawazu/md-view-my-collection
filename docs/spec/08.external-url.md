# 外部URL管理機能 — 仕様書

## 概要

レポートに外部URL（note / Zenn / はてなブログ / 一般サイト等）を**複数**紐付けて保存・閲覧する機能を追加する。

## 背景・動機

- 良かったnote記事や技術ブログのURLを記録・振り返りたい
- 新規プロジェクトではなく、既存の md-view-my-collection に機能追加する
- note専用ではなく、あらゆる外部URLに対応する汎用設計とする

## 機能要件

### FR-1: URL登録（レポート作成・編集フォーム）

- レポートの新規作成・編集フォームにURL入力セクションを追加する
- 1レポートに対して**0件〜N件**のURLを登録できる
- 各URLは「URL（必須）」と「ラベル（任意）」のペアで入力する
- 「+ URL追加」ボタンで入力行を動的に追加できる
- 各行に「削除」ボタンを設置し、個別に削除できる
- URL 0件のまま投稿・更新可能（URLは任意項目）

### FR-2: URL表示（レポート詳細画面）

- 紐付くURLが**1件以上**ある場合、タグセクションの上にリンク一覧セクションを表示する
- URLが0件の場合はリンクセクション自体を非表示にする
- 各URLはクリッカブルリンクとして描画する（`target="_blank"` / `rel="noopener noreferrer"`）
- ラベルがある場合はラベルをリンクテキストとして表示する
- ラベルがない場合はURLをそのまま表示する

### FR-3: URL削除（レポート削除連動）

- レポート削除時、紐付く全URLも連動して削除される（CASCADE）

## データ要件

### ExternalUrl（新規テーブル）

| フィールド | 説明 | 制約 |
|---|---|---|
| id | 一意識別子 | PK |
| reportId | 紐付け先レポートID | FK → Report.id, NOT NULL |
| url | 外部URL | NOT NULL |
| label | 表示ラベル | NULLABLE |
| createdAt | 登録日時 | NOT NULL |

- 既存 Report テーブルへの変更なし
- 1 Report : N ExternalUrl（1対多）
- Report 削除時は ExternalUrl も CASCADE 削除

### バリデーション

| フィールド | ルール |
|---|---|
| url | 必須、URL形式（`https://` または `http://` で始まる） |
| label | 任意、最大200文字 |

## アクセス制御

| 操作 | 権限 |
|---|---|
| 閲覧 | 誰でも（未ログインでも表示） |
| 登録・更新・削除 | 認証ユーザーのみ |

※ 既存の Report / ReportTag / ReportTagMapping と同じ RLS ポリシーを適用する。

## 画面仕様

### 詳細画面（/report/:id）

- タグチップ一覧の上に「外部リンク」セクションを配置する
- セクション見出し: 「External Links」（SectionLabel 相当）
- 各リンクは箇条書きリスト形式で表示する
- リンク末尾に外部リンクアイコン（↗）を付与する
- URL 0件の場合はセクション自体を非表示にする

### フォーム画面（/report/new, /report/:id/edit）

- タグ入力フィールドの下に「外部リンク」セクションを配置する
- セクション見出し: 「External Links」
- 各行の構成: `[URL入力] [ラベル入力] [✕ 削除ボタン]`
- セクション末尾: `[+ URL追加]` ボタン
- 編集画面では既存URLをフォームに初期表示する

## E2Eテストケース

> 実装時に `docs/spec/04.e2e-cases.md` に追記する。

### TC-026 正常: URL 0件の詳細表示

- 前提: URLが紐付いていないレポート
- 手順: 詳細画面を開く
- 期待: 外部リンクセクションが表示されない

### TC-027 正常: URL複数件の詳細表示

- 前提: URL 2件以上が紐付いたレポート（ラベルあり / なし混在）
- 手順: 詳細画面を開く
- 期待: 全URLがクリッカブルリンクとして表示される。ラベルありはラベル表示、ラベルなしはURL表示

### TC-028 正常: 新規作成でURL追加

- 前提: ログイン済
- 手順: 新規作成 → URL 2件追加（1件はラベルあり、1件はラベルなし） → 投稿
- 期待: 詳細画面で2件のリンクが表示される

### TC-029 正常: 編集でURL追加・削除

- 前提: ログイン済、URL 1件紐付きのレポート
- 手順: 編集画面を開く → 既存URL 1件を確認 → 新規URL 1件追加 → 既存URL 1件削除 → 保存
- 期待: 詳細画面で新しいURL 1件のみ表示される

### TC-030 異常: 不正URL入力

- 前提: ログイン済
- 手順: URL欄に URL形式でない文字列を入力して投稿
- 期待: バリデーションエラー表示、送信不可
